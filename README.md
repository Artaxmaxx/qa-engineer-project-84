# Тестирование проекта Hexlet Store (products-store.hexlet.app)

## 📌 О тестируемом проекте
**Hexlet Store** — это учебный интернет-магазин, разработанный на платформе Hexlet для отработки навыков ручного тестирования веб-приложений. Приложение представляет собой SPA (Single Page Application).

**Ключевые особенности и функционал проекта:**
*   **Каталог товаров:** Просмотр списка товаров с возможностью фильтрации по категориям, брендам и цене.
*   **Карточка товара:** Отображение названия, рейтинга, цены со скидкой и без, а также описания.
*   **Корзина:** Возможность добавлять товары в корзину, просматривать их, изменять количество и удалять. Корзина хранится в сессии браузера.
*   **Оформление заказа:** Процесс оформления заказа с переходом на страницу оплаты.
*   **Пагинация:** Постраничный вывод товаров в каталоге.
*   **Адаптивная вёрстка:** Интерфейс должен корректно отображаться на мобильных устройствах и десктопах.

## 📂 Содержимое репозитория
Данный репозиторий содержит полный набор документов, созданных в процессе тестирования интернет-магазина Hexlet Store:

*   **`requirements.yml`** — Анализ требований:
    *   `functional` — функциональные требования к приложению.
    *   `non-functional` — нефункциональные требования (например, производительность, адаптивность).
    *   `implicit` — неявные требования, выявленные в ходе анализа.

*   **`test-cases.yml`** — Тест-кейсы:
    *   Подробные сценарии проверки функционала магазина (просмотр каталога, фильтрация, работа с корзиной, оформление заказа).

*   **`testing-report.yml`** — Отчёт о тестировании:
    *   Результаты прогона всех созданных тест-кейсов с указанием статуса (Passed/Failed).

*   **`bugreports.yml`** — Баг-репорты:
    *   Задокументированные дефекты, найденные в ходе тестирования, с шагами воспроизведения, ожидаемым и фактическим результатом.

*   **`regress-report.yml`** — Отчёт о регрессионном тестировании:
    *   Результаты повторной проверки ключевых сценариев после исправления багов или внесения изменений.

*   **`about.yml`** — Информация о проекте и тестировщике (ФИО, уровень, контакты).
